# Example station metadata

`stations_template.csv` is a **synthetic illustration**, not actual CTD measurements.
The HEX files named in the table are placeholders and are **not included**.
Replace with real, authorized campaign metadata and a matching instrument XMLCON.
The first run can also use discovery mode (option 3) with only `.hex` and `.xmlcon`.
Station locations are decimal degrees, longitude negative west, WGS84.
The time-zone offsets must be checked in `AUTO_CFG` for every campaign.
