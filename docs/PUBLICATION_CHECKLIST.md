# Public release checklist

- [ ] Confirm rights to redistribute the script, especially employer or collaborator contributions.
- [ ] Confirm no institutional or confidential data appear anywhere in the code, examples, metadata or Git history.
- [ ] Confirm no sensor configuration, serial/calibration records or cruise reports are unintentionally included.
- [ ] Test installation in a clean Python environment; record interpreter and package versions.
- [ ] Run on **authorized** HEX + matching XMLCON and verify decoded ranges, timestamps and sensor QC against trusted products.
- [ ] Check station assignments, time zones, static/profiling classification and review exceptions.
- [ ] Verify the Excel output is accepted by the water-mass analyzer; compare several hydrographic estimates with an independent method.
- [ ] Validate any OMP end-member and oxygen assumptions for the chosen region.
- [ ] Add a screenshot of genuine outputs only if the underlying data can be released.
- [ ] Decide and document repository license if public reuse is authorized.
- [ ] Upload only repository contents (not parent folder archives with unrelated files).
